Built for heavy worlds.

Cubimised API brings custom terrain rendering, visibility filtering, chunk-section rebuilding, GPU buffer management and adaptive performance features together for Minecraft 1.20.1.

Features

Custom Renderer

Section-based terrain meshes, render-layer batching and GPU buffers.

Smart FPS Booster

Adaptive performance controls based on frame-time pressure.

Visibility & Culling

Distance and entity-focused culling to reduce unnecessary rendering work.

MTR Friendly

Designed with demanding Minecraft Transit Railway environments in mind.

Adaptive View Distance

Can adjust view distance when sustained performance pressure is detected.

GPU Buffer Pooling

Reuses renderer buffers to reduce allocation pressure.
